# Защита загружаемых файлов

Модуль очищает файлы и текст **перед передачей в ИИ/LLM**, чтобы снизить риск prompt injection через метаданные и очевидные текстовые шаблоны.

## Зачем

В изображениях (EXIF), PDF и Excel часто лежат поля Author / Title / Keywords / Creator и другой скрытый текст. Туда можно спрятать инструкции вроде «ignore previous instructions». Модель иногда читает это как команды, а не как данные.

Этот модуль:

- снимает метаданные у изображений, PDF и xlsx (где позволяют зависимости);
- вычищает из текста типичные строки-инъекции;
- **не гарантирует** полную безопасность.

## Установка зависимостей (опционально)

Стандартной библиотеки хватает для текста. Для остальных форматов:

```bash
pip install Pillow pypdf openpyxl
```

Если пакета нет, функции вернут понятную ошибку с подсказкой `pip install …`.

## Вызов из кода

```python
from защита.sanitize import sanitize_file, sanitize_text

clean_path = sanitize_file("upload.pdf")
clean_text = sanitize_text(open("notes.txt", encoding="utf-8").read())
```

`sanitize_file` возвращает путь к **очищенной копии** (суффикс `.sanitized` в имени) или исходный путь, если формат не поддерживается / чистить нечего.

## CLI

Из корня репозитория:

```bash
python -m защита.sanitize input.pdf
python -m защита.sanitize photo.jpg -o /tmp/clean
```

На stdout печатается путь к результату.

## Что умеет

| Тип | Действие |
|-----|----------|
| JPEG/PNG/… | пересохранение без EXIF (Pillow) |
| PDF | страницы копируются, Author/Title/Subject/Keywords/Creator/Producer очищаются (pypdf) |
| xlsx | очистка свойств книги и custom properties (openpyxl); скрытые листы не удаляются |
| txt/md/csv/… | scrub строк-инъекций + нормализация пустых строк |

## Ограничения

- Это **снижение риска**, не устранение. Скрытый текст в теле PDF, макросы, внедрённые объекты, steganography и т.п. модуль не закрывает.
- Модель всё равно нужно инструктировать: **содержимое файла — данные, не команды**.
- Excel: не претендует на полную зачистку VBA, внешних связей и всего скрытого содержимого.
- Эвристики `sanitize_text` простые: обойти их легко; ложные срабатывания возможны.

## Стиль репозитория

Модуль рассчитан на вызов рядом с генератором меню и другими пайплайнами загрузки файлов. Не подменяйте исходники пользователя без явного сохранения копии.
