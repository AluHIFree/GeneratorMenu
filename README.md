# GeneratorMenu
Программа для генерации меню для школ на основе типового меню и календаря питания
Генератор ЕМ автоматически формирует файлы ежедневных меню на основе типового (цикличного) меню — файл tm*-sm.xlsx — и календаря питания kp*.xlsx. Поддерживаются два типа питания: только завтраки либо завтраки и обеды. Меню для интернатов программа пока формировать не умеет.

Формирование ЕМ из типового меню и календаря питания
Поддержка файлов tm*-sm.xlsx и kp*.xlsx
Типы питания: только завтраки; завтраки и обеды
